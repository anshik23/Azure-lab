# Lab 09B – Implement Azure Container Instances

## Overview

This lab focuses on deploying and managing Azure Container Instances (ACI) using Docker container images. It demonstrates how to run containerized applications in Azure without provisioning or managing virtual machines or other underlying infrastructure.

## Objectives

- Deploy an Azure Container Instance using a Docker image.
- Configure container networking and DNS.
- Access a containerized web application through a public URL.
- Verify container instance deployment and status.
- Monitor application activity through container logs.

## Prerequisites

- An active Microsoft Azure subscription.
- Access to the Azure Portal.
- Basic understanding of Docker and containerization.
- Familiarity with Azure resource groups and networking.

## Implementation

### Task 1: Deploy an Azure Container Instance Using a Docker Image

- Opened the Azure Portal.
- Navigated to Container Instances.
- Created a new Azure Container Instance.
- Configured the following settings:
  - Resource Group: `az104-rg9`
  - Container Name: `az104-c1`
  - Region: East US
  - Image Source: Quickstart Images
  - Image: `mcr.microsoft.com/azuredocs/aci-helloworld:latest`
  - Operating System: Linux
- Configured a globally unique DNS name label.
- Disabled container instance logs during initial deployment.
- Reviewed the advanced configuration settings.
- Validated and deployed the container instance.
- Verified successful resource deployment.

### Task 2: Test and Verify Deployment of an Azure Container Instance

- Opened the deployed container instance.
- Verified that the container status was Running.
- Retrieved the Fully Qualified Domain Name (FQDN).
- Opened the container application using its public DNS URL.
- Verified that the Welcome to Azure Container Instance page was displayed.
- Refreshed the application several times to generate HTTP request logs.
- Navigated to the Containers section.
- Opened the Logs section.
- Verified HTTP GET request entries generated by accessing the application.
- Confirmed successful deployment and application accessibility.

## Results

Successfully deployed an Azure Container Instance using a Docker quickstart image, configured public DNS access, verified the running containerized web application, and examined application activity through container logs.

## Key Learnings

- Azure Container Instances provide a serverless container hosting solution.
- Docker images package applications and their dependencies into portable containers.
- ACI eliminates the need to manage underlying virtual machines.
- Container instances support Linux and Windows containers.
- DNS labels provide a publicly accessible endpoint for containerized applications.
- Container logs help monitor application activity and troubleshoot issues.
- ACI is suitable for workloads that require quick container deployment without complex orchestration.
